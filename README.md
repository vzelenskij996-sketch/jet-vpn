# Jet VPN

Node.js-бэкенд + фронтенд для VPN-сервиса: лендинг, личный кабинет, тестовый период,
онлайн-поддержка в реальном времени (чат с админами) и админ-панель с репортами.

## Запуск

```bash
npm install
cp .env.example .env
# отредактируйте .env: JWT_SECRET, ADMIN_EMAIL/ADMIN_PASSWORD, данные панели 3x-ui
npm start
```

Локально: http://localhost:3000
Админка: /admin.html (логин/пароль — из `.env`, `ADMIN_EMAIL` / `ADMIN_PASSWORD`, админ создаётся автоматически при первом запуске)

## Деплой на свой домен

Сервер слушает обычный HTTP-порт (по умолчанию 3000), домен и HTTPS вешаются через
reverse proxy. Кратко:

1. Залейте папку проекта на сервер, `npm install`, заполните `.env` (в `SITE_URL`
   впишите `https://ваш-домен.ru`).
2. Держите процесс живым через pm2: `npm i -g pm2 && pm2 start server.js --name jetvpn`.
3. Поставьте Nginx как reverse proxy на 80/443, проксируя на `127.0.0.1:3000`
   (Socket.io работает через WebSocket — в конфиге нужно прокинуть заголовки
   `Upgrade`/`Connection`, это стандартная настройка для Node+WS за Nginx).
4. Выпустите сертификат: `certbot --nginx -d ваш-домен.ru`.
5. Пропишите DNS A-запись домена на IP сервера — и всё открывается уже по домену.

## Структура

```
server.js           — Express + Socket.io (чат поддержки в реальном времени)
routes/auth.js       — регистрация, вход, запуск тестового периода
routes/admin.js      — вход админа, список пользователей, тикеты, репорты
routes/support.js    — создание тикетов поддержки
data/db.js           — файловая БД (lowdb, data/db.json) — для старта; замените на Postgres/Mongo при росте
data/xui.js          — интеграция с панелью 3x-ui (создание/удаление клиентов)
public/              — фронтенд: index.html (лендинг+чат), admin.html (панель админа)
```

## Что нужно донастроить самому

1. **3x-ui**: в `.env` укажите `XUI_PANEL_URL`, `XUI_USERNAME`, `XUI_PASSWORD`, `XUI_INBOUND_ID`.
   Проверьте пути запросов в `data/xui.js` под версию вашей панели — у разных форков
   3x-ui эндпоинты API могут немного отличаться.
2. **Платежи**: сайт не содержит платёжной интеграции — вы говорили, что настроите её
   сами. Кнопки тарифов на лендинге сейчас ведут в форму регистрации; подключите
   свой платёжный провайдер и по вебхуку об успешной оплате обновляйте `user.plan`
   в `data/db.json` (или вызывайте `xui.createClient` с нужным сроком/объёмом трафика).
3. **База данных**: `lowdb` хранит всё в `data/db.json` — удобно для старта и тестов,
   но под нагрузкой 100+ клиентов стоит перейти на PostgreSQL или MongoDB.
4. **HTTPS**: заведите сервис за Nginx/Caddy с TLS-сертификатом перед продакшеном.

## Онлайн-поддержка

Пользователь открывает чат-пузырь на сайте → создаётся тикет → сообщение уходит
всем подключённым админам через Socket.io в реальном времени. Админ отвечает из
вкладки «Поддержка» в админ-панели — ответ сразу появляется в чате пользователя.

## Репорты

Во вкладке «Репорты» админ может создавать текстовые отчёты (например, сводки
по инцидентам или статистике) — они сохраняются и видны всем админам.
